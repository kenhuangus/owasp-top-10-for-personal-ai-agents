# Crosswalk

Proposed analytical crosswalk to the OWASP Top 10 for Agentic Applications 2026 (ASI) and the OWASP Top 10 for LLM Applications 2025. It identifies related mechanisms and controls, not equivalence or endorsement. The ASI column follows the project proposal; the LLM column is an initial draft for maintainer review. Machine-readable: [`crosswalk.json`](../crosswalk/crosswalk.json).
